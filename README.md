This repository contains the work, documentation, research, and development of our **Business Information Systems (BIS) Graduation Project**.

## 📋 Planned Project Development

Although the exact project is not defined yet, we expect the graduation project to go through the following stages:

1. **Idea Generation**
2. **Problem Identification**
3. **Market & User Research**
4. **Project Idea Selection**
5. **Requirements Analysis**
6. **System Analysis & Design**
7. **Database Design**
8. **UI/UX Design**
9. **System Development**
10. **Testing**
11. **Documentation**
12. **Final Presentation & Graduation**
